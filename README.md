# ByStep Mods Repository

Моды, шейдеры и ресурспаки для ByStep Launcher.

## Структура

```
mods/
├── 1.20.1-fabric/          # Minecraft 1.20.1 Fabric
│   ├── *.jar               # Моды
│   └── shaderpacks/
│       ├── High/           # Шейдеры для мощных ПК
│       └── Low/            # Шейдеры для слабых ПК
└── 1.21.1-fabric/          # Minecraft 1.21.1 Fabric
    ├── *.jar               # Моды
    ├── shaderpacks/        # Шейдеры
    └── resourcepacks/      # Текстурпаки
```

## Версии

- **1.20.1 Fabric** - сборка с Man From The Fog, выбор качества шейдеров (High/Low)
- **1.21.1 Fabric** - основная сборка с физикой, снегом, шейдерами
