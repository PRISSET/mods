# ByStep Mods Repository

Моды, шейдеры и ресурспаки для ByStep Launcher.

## Структура

```
mods/
└── 1.21.1-fabric/          # Minecraft 1.21.1 Fabric
    ├── *.jar               # Моды
    ├── shaderpacks/        # Шейдеры
    └── resourcepacks/      # Текстурпаки
```

## Версия

- **1.21.1 Fabric** - основная сборка с модами, шейдерами и текстурпаками
